# Settl Explainer Page

This static web page explains Settl and demonstrates its stage path rules with an interactive simulator.

Settl turns a deal written in plain words into a locked agreement. People join, pretend money is locked, and each person is paid only when their stage is approved.

## How to Open

Open `site/index.html` directly in any standard web browser. No web server, build tools, external libraries, or network connection are required.

## Simulator Rules & Roles

- **Payer (Riya):** Locks the initial funds (30,000 rupees) and can approve or dispute completed stages.
- **Payee (Aman):** Performs work, marks pending stages done, and withdraws released funds.
- **Judge (Meera):** Resolves disputed stages by releasing payment or refunding to the payer.
- **Stranger:** Unrelated third party with no permissions to alter stage states or withdraw.
